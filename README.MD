CHINEDU GOODLUCK - STUDENT PORTFOLIO
====================================

PAGES
- index.html: Home
- about.html: Biography, education, career goal, skills and interests
- projects.html: Three beginner sample project concepts
- planner.html: Interactive academic task planner
- contact.html: Contact form with JavaScript validation


FOLDER CONTENTS
- css/style.css: external stylesheet
- js/script.js: mobile menu, academic planner and form validation
- images/chinedu.jpg: supplied profile photograph
- images/*.svg: simple sample project preview images
- audio/: add sample-audio.mp3 here if you want to use the audio player

JAVASCRIPT FEATURES
- Add, complete/undo and delete planner tasks
- Save tasks in browser localStorage
- Validate that contact form fields are completed
- Check email format
- Check that phone number contains digits only
- Mobile navigation menu
